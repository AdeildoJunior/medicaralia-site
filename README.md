# Medicaralia

Plataforma acessível de visibilidade e agendamento para profissionais de saúde em início de carreira.

## MVP inicial

- Página inicial pública
- Busca por especialidade, cidade e bairro
- Cards de profissionais
- Cadastro de profissionais interessados
- Estrutura preparada para painel interno
- Dados iniciais em JSON
