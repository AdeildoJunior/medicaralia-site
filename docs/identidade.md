# Identidade Visual — Medicaralia

## Direção

A Medicaralia deve parecer moderna, acessível, confiável e jovem.

## Não copiar

- cores da Doctoralia;
- layout idêntico;
- textos;
- ícones proprietários;
- identidade visual de concorrentes;
- nomes de planos ou seções iguais.

## Pode usar como referência genérica

- busca central;
- cards de profissionais;
- filtros por especialidade e região;
- CTA para cadastro profissional;
- layout limpo;
- experiência mobile-first.

## Sugestões de tom

- acessível;
- direto;
- acolhedor;
- profissional;
- sem parecer plataforma elitizada.
