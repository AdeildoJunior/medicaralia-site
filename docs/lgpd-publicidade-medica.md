# LGPD e Publicidade Médica — Diretrizes Iniciais

## Diretriz geral

A Medicaralia deve ser construída desde o início com cuidado em relação à LGPD, publicidade médica e dados sensíveis.

## Evitar

- promessas de cura;
- rankings enganosos;
- exposição indevida de dados de pacientes;
- depoimentos irregulares;
- antes e depois em áreas sensíveis;
- uso de termos que induzam garantia de resultado;
- copiar identidade visual de concorrentes;
- usar nome de concorrente em anúncios.

## Permitido como direção inicial

- página profissional informativa;
- especialidade;
- cidade/bairro;
- canais de contato;
- formação;
- número de registro profissional quando aplicável;
- serviços oferecidos;
- aviso de que informações não substituem consulta profissional.

## Dados

No MVP, evitar coletar dados clínicos de pacientes. Coletar apenas dados mínimos de contato quando necessário.
